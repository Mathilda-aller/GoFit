# 「练过」交互 Demo 设计说明

> 版本：v2.0  
> 对应 PRD：`PRD_健身视频重构_v0.1.md` v0.7  
> 文档用途：设计、前端、后端和 AI 同学共同确认产品长什么样，并据此制作可点击原型和 Demo  
> 本文只说明页面、信息、操作和状态，不规定颜色、字体、插画风格或视觉效果

---

## 1. 先用一句话理解产品

用户把一条健身教学视频交给「练过」，AI 将它整理成一张训练时可以直接使用的视频动作卡；用户把卡片加入一份可保存的练单、按练单训练并反馈体感。如果用户没找到感觉，系统会从讲同一动作的多个视频评论区中，找到已经整理好的练友经验帮助他调整。

完整主流程是：

```text
视频接入
  → AI 解析
  → 生成视频动作卡
  → 加入或新建练单
  → 开始训练
  → 练后体感反馈
  → 有问题时查看练友经验
  → 记录结果并影响下次推荐
```

动作知识库是 P1，不改变以上 P0 主流程。

## 2. 所有人必须统一理解的五个东西

### 2.1 来源视频

用户在抖音看到的原始健身教学视频。系统必须保存视频标题、创作者、封面、原视频入口和可回看的时间位置。

### 2.2 视频动作卡

一条视频对应一张视频动作卡。卡片只整理这条视频明确表达的内容，包括动作步骤、关键提示、目标肌群和示范片段。

例如，A 教练的视频动作卡不能混入 B 教练的教学观点，也不能把评论区建议写成 A 教练说过的话。

用户真正收藏、加入练单和训练时使用的，都是具体的视频动作卡。

### 2.3 标准动作

标准动作是后台用来连接内容的名字，例如“高位下拉”“哑铃侧平举”。

标题不同的多个视频可能都在讲同一个标准动作：

```text
“宽握下拉怎么找背部感觉”
“背部训练新手教程”
“Lat Pulldown 教学”
              ↓
         标准动作：高位下拉
```

P0 中，标准动作不是一张需要用户训练的卡，也不需要单独做百科页面。它只是让系统知道哪些视频和评论可以放在一起整理。

### 2.4 练友经验，也就是 P0 动作关联层

系统把讲同一个标准动作的多个视频评论区放到一起，再按照问题和解决方法整理。

例如，多条“高位下拉”视频下都有人问“为什么手臂先酸”，系统会把这些评论归到同一个问题中，整理出大家常提到的方法，并保留原视频和原评论入口。

用户看到的名称统一叫“练友经验”，不在界面上展示“动作关联层”这个内部名称。

### 2.5 练单与本次训练

**练单**是用户自己创建并保存的视频动作卡组合，例如“肩部入门”“周末练背”。练单可以命名、修改、复制并多次使用。

**本次训练**是用户点击“开始训练”后，由某一份练单复制出来的一次执行记录。本次训练保存完成进度和体感，但不会自动改动原来的练单。

系统可以为正在编辑的练单推荐候选动作，但不能自动把动作放进练单。

## 3. P0 和 P1 的边界

| 内容 | P0：本次必须做 | P1：后续再做 |
| --- | --- | --- |
| 一条视频生成一张视频动作卡 | 是 | 继续完善 |
| 视频动作卡加入练单并用于训练 | 是 | 继续完善 |
| 多个同动作视频的评论聚类为练友经验 | 是 | 扩大数据量和更新范围 |
| 练后根据体感找到相关练友经验 | 是 | 做更细的个人匹配 |
| 独立动作知识页 | 否 | 是 |
| 聚合多个视频本身的教学共识和不同观点 | 否 | 是 |
| 将足量、去掉身份信息的训练反馈汇总到动作知识中 | 否 | 是 |

P0 的动作库展示具体的视频动作卡。P1 才增加“高位下拉知识页”这类独立动作知识入口。

## 4. 整体页面结构

### 4.1 一级入口

App 底部只有三个一级入口：

1. **练单**：新建、保存、编辑和再次使用练单；
2. **动作库**：查看、搜索和添加视频动作卡；
3. **我的**：查看健身搭子、练过记录、体感记录和个人设置。

“练友经验”没有独立一级入口，只从具体视频动作卡或练后反馈进入。

“动作知识库”是 P1 页面，也不增加新的底部入口。

### 4.2 P0 页面清单

| 编号 | 页面 | 主要用途 |
| --- | --- | --- |
| P00 | 模拟抖音视频页 | 说明视频来源 |
| P01 | 视频接入与处理页 | 确认视频并展示处理结果 |
| P02 | 视频动作卡详情 | 学习动作、查看速记、加入练单 |
| P03 | 练单首页 | 新建练单、查看已保存练单和继续训练 |
| P03A | 练单详情／编辑 | 查看、编辑并再次使用某份练单 |
| P04 | 动作选择页 | 从动作库或推荐中添加具体动作卡 |
| P05 | 动作库 | 管理视频动作卡 |
| P06 | 训练执行页 | 按动作卡逐个训练 |
| P07 | 练后体感面板 | 记录本次真实感觉 |
| P08 | 练友经验页 | 查看同动作、跨视频的评论经验 |
| P09 | 不适安全提示页 | 处理疼痛或不适反馈 |
| P10 | 训练完成页 | 汇总本次训练结果 |


## 5. 用户从头到尾怎样走完整个产品

### 5.1 主 Demo 故事

本次 Demo 用“哑铃侧平举”为主动作，准备：

- 1 条现场展示 AI 解析的视频；
- 2—4 条已经预置好的同动作来源视频；
- 来自这些视频的公开评论样本；
- 一组已经聚类完成的练友经验；
- 3—4 张可加入练单的视频动作卡；
- 一份模拟历史体感数据。

### 5.2 完整演示步骤

1. 用户在模拟抖音页看到“哑铃侧平举教学”；
2. 点击分享面板中的“用练过打开”；
3. 进入视频接入页，确认视频来源；
4. 系统展示 AI 处理过程，随后打开视频动作卡；
5. 用户先看完整步骤，再切换到训练速记；
6. 点击“加入练单”，选择“新建练单”；
7. 将练单命名为“今天练肩”，视频动作卡已经加入；
8. 系统提供不超过 3 个候选动作和推荐理由；
9. 用户手动添加第二张动作卡、调整顺序并保存练单；
10. 点击“开始训练”，系统以这份练单创建一次本次训练；
11. 按第一张卡训练后点击“练过”；
12. 选择“目标部位有感觉”，保存反馈并进入下一动作；
13. 第二个动作练完后选择“其他部位更酸”，再选择“手臂”；
14. 系统按“标准动作 + 手臂代偿”找到相关练友经验；
15. 用户进入练友经验页，看到经验来自多条同动作视频的评论，而不是当前单条视频；
16. 用户查看一种方法和对应原评论，标记“对我有用”；
17. 返回训练并完成本次训练；
18. 完成页显示完成动作、体感摘要和下次推荐会参考的记录；
19. 用户回到“练单”，仍能看到保存的“今天练肩”，以后可以再次使用。

## 6. 全局交互规则

### 6.1 页面返回

- 从模拟抖音页进入「练过」后，返回可回到模拟抖音页；
- 从练单详情打开动作卡，关闭后回到该练单原来的位置；
- 从动作库打开动作卡，关闭后回到动作库原来的筛选结果；
- 从训练中打开完整动作步骤或练友经验，返回后仍停留在当前动作，训练进度不能丢失；
- 训练中点击退出时，必须先询问“保存进度并退出”还是“继续训练”。

### 6.2 加入练单

- 视频动作卡上的统一按钮为“加入练单”；
- 从某份练单的动作选择页进入时，点击后直接加入当前练单；
- 从视频动作卡详情或动作库直接点击时，先打开“选择练单”面板；
- “选择练单”面板先显示最近编辑的练单，再显示其他已保存练单，并提供“新建练单”；
- 选择某份练单后，将卡片加入该练单末尾，并显示“已加入：练单名称”；
- 同一张视频动作卡不能在同一份练单中重复加入，但可以存在于不同练单中；
- 加入成功后提供“查看这份练单”；
- AI 推荐只能等待用户点击“加入”，不能自动添加。

### 6.3 收藏、加入练单和开始训练是三件事

- 收藏：保存到动作库，供以后使用；
- 加入练单：把视频动作卡保存到一份可重复使用的练单中；
- 开始训练：复制当时的练单内容，创建一次独立训练记录；
- 用户可以不收藏，直接把卡片加入某份练单；
- 用户删除练单中的动作时，不影响它在动作库里的收藏状态；
- 训练中的完成进度和体感，不会自动改变原练单的动作与顺序。

### 6.4 数据保存

- 新建练单后立即建立草稿；
- 修改练单名称、动作或顺序后自动保存；
- 已保存练单可以多次使用，开始训练不会删除或清空它；
- 训练每完成一个动作后立即保存进度和体感；
- 页面刷新或短暂断网后，应能恢复到最近一次已保存状态；
- 未公开的训练反馈只属于当前用户，不能自动显示到练友经验中。

### 6.5 内容来源

界面中只使用以下三个用户能理解的来源名称：

- **来自本视频**：创作者在当前视频中表达的内容；
- **来自练友**：多个公开视频评论或用户主动公开的经验；
- **AI 整理**：AI 对公开内容的归类和摘要。

不得把“来自练友”或“AI 整理”放进“本视频步骤”中。

## 7. P00 模拟抖音视频页

### 7.1 页面目的

让观看 Demo 的人明白：用户是在抖音发现视频，再把视频交给「练过」使用。

### 7.2 页面信息

页面包含：

1. 原始健身教学视频；
2. 创作者昵称；
3. 视频标题和简短说明；
4. 点赞、评论、收藏和分享入口；
5. 分享面板中的“用练过打开”。

其他抖音功能只做展示，不需要完整实现。

### 7.3 操作

- 点击“分享”：打开分享面板；
- 点击“用练过打开”：进入 P01 视频接入与处理页；
- 进入时把 `videoId` 传给下一页；
- 其他分享选项不进入主流程。

## 8. P01 视频接入与处理页

### 8.1 页面目的

确认用户导入的是哪条视频，并处理“这张公共视频动作卡是否已经存在”。

### 8.2 页面信息

从上到下展示：

1. 视频封面；
2. 视频标题；
3. 创作者；
4. 来源平台；
5. 当前处理状态；
6. 主操作按钮；
7. “返回原视频”。

### 8.3 状态一：公共视频动作卡已存在

提示：

> 这条视频已经整理成动作卡。

按钮：

- “查看动作卡”：进入 P02；
- “返回原视频”：回到 P00。

不要重复运行 AI，也不要伪造新的生成过程。

### 8.4 状态二：需要生成动作卡

按顺序展示四个处理步骤：

1. 正在读取画面、语音和字幕；
2. 正在确认动作和关键时间；
3. 正在整理步骤、提示和肌群；
4. 正在生成示范片段和动作卡。

完成后显示“动作卡已生成”，按钮变为“查看动作卡”。

这里展示的是处理状态，不要求用户输入提示词或与 AI 对话。

### 8.5 失败状态

根据失败原因显示一个明确结果：

- 视频无法读取：允许重试或返回；
- 语音和字幕都无法识别：说明暂时无法生成可靠卡片；
- 无法确认具体动作：提示需要人工确认标准动作；
- 无法找到可靠片段：仍可生成文字卡，但不展示错误示范或循环片段；
- 网络中断：保留已完成步骤并允许继续。

## 9. P02 视频动作卡详情

### 9.1 页面目的

让用户快速理解当前视频教了什么，并决定收藏、加入练单或返回原视频。

### 9.2 页面顶部信息

始终显示：

- 动作名称；
- 来源视频标题；
- 创作者；
- “来自本视频”；
- 收藏状态；
- 返回入口。

### 9.3 第一层：训练速记

这是用户从训练执行页进入时的默认内容，也可以在详情页主动切换查看。

内容顺序：

1. 动作名称；
2. 正确示范循环片段或代表画面；
3. 动作暗号，例如“肩放松 → 肘带动 → 缓慢落”；
4. 最多 3 条短提示；
5. 主要肌群和辅助肌群；
6. “查看完整步骤”。

### 9.4 第二层：完整步骤

这是用户从视频接入页或动作库进入时的默认内容。

内容顺序：

1. 动作名称；
2. 主要肌群、辅助肌群和器械；
3. 正确示范片段；
4. 3—5 个动作步骤；
5. 当前视频明确提到的关键提示；
6. 当前视频明确提供的错误示范和纠正提示；
7. 每条内容对应的原视频时间；
8. “查看训练速记”。

原视频没有错误示范时，整个错误模块不显示，不保留空位置，也不由 AI 补写。

### 9.5 页面底部内容

完整步骤和训练速记共用以下操作：

- “加入练单”；
- “收藏”／“已收藏”；
- “返回原视频”；
- “查看练友经验”。

“查看练友经验”旁边显示它的跨视频来源，例如：

> 练友经验｜整理自 4 条同动作视频的 68 条公开评论

这句话是 P0 动作关联价值最重要的界面表达，不能只写成模糊的“看看大家怎么说”。

### 9.6 页面操作

- 点击“查看完整步骤”和“查看训练速记”：只切换当前卡片的信息层，不创建第二张卡；
- 点击某个时间：从该位置打开原视频片段；
- 点击“加入练单”：打开“选择练单”面板；选择已有练单后加入其末尾，或新建练单后加入；
- 加入成功后显示练单名称，并提供“查看这份练单”：进入 P03A；
- 点击“查看练友经验”：进入 P08，默认展示该标准动作的热门问题；
- 从训练中进入本页时，关闭后返回 P06 当前动作。

### 9.7 页面状态

- 已收藏／未收藏；
- 尚未加入任何练单／已加入一份或多份练单；
- 有可靠示范片段／只有代表画面；
- 有错误示范／没有错误示范；
- 有练友经验／经验样本不足；
- 内容可用／部分内容需要人工确认。

经验样本不足时显示：

> 暂时没有足够的同动作评论可供整理，你仍可以查看原评论。

## 10. P03 练单首页与 P03A 练单详情

### 10.1 模块目的

“练单”就是用户自己创建并保存的训练计划，不是只服务今天的一次性清单。用户可以在这里新建练单、保存以前搭好的训练安排，并在以后再次使用。

### 10.2 P03 练单首页结构

页面从上到下包含：

1. 标题“练单”；
2. 未完成训练入口；
3. “新建练单”；
4. “我的练单”；
5. 最近使用记录。

### 10.3 未完成训练入口

如果当前有尚未完成的训练，在页面最前面显示：

- 来源练单名称；
- 当前进度，例如“已完成 1／3”；
- 上次保存时间；
- “继续训练”；
- “结束这次训练”。

P0 同一时间只保留一份进行中的训练。用户准备开始另一份练单时，先选择继续、结束或放弃当前训练。

### 10.4 新建练单

点击“新建练单”后：

1. 建立一份空练单草稿；
2. 默认名称为“未命名练单”；
3. 进入 P03A 练单详情；
4. 用户可以修改名称；
5. 点击“添加动作”进入 P04；
6. 修改内容时自动保存。

如果用户是从视频动作卡的“加入练单 → 新建练单”进入，新练单建立后应自动包含那张视频动作卡。

### 10.5 我的练单列表

每份已保存练单显示：

- 练单名称；
- 包含的动作数量；
- 前几张视频动作卡名称；
- 主要覆盖部位；
- 最近使用时间；
- 已使用次数；
- “开始训练”；
- 更多操作。

更多操作包括：

- 编辑；
- 复制一份；
- 重命名；
- 删除。

点击练单主体进入 P03A。点击“开始训练”直接基于这份练单创建一次本次训练，并进入 P06。

删除练单前必须确认。删除练单不会删除动作库里的视频动作卡，也不会删除过去已经完成的训练记录。

### 10.6 没有保存练单时

显示：

> 还没有保存的练单。新建一份，把想练的视频动作卡放进去，以后可以直接再用。

提供：

- “新建练单”；
- “从动作库开始”。

### 10.7 P03A 练单详情／编辑结构

页面从上到下包含：

1. 练单名称；
2. 上次保存时间；
3. 动作数量和使用次数；
4. 整份练单的肌群概览；
5. 按顺序排列的视频动作卡；
6. “添加动作”；
7. “接下来可以考虑”；
8. “开始训练”；
9. 复制、重命名和删除。

练单名称点击后可以编辑。修改名称、动作或顺序后自动保存，并明确显示“已保存”。

### 10.8 每个练单动作项

显示：

- 顺序；
- 示范画面；
- 动作名称；
- 来源创作者；
- 主要肌群；
- 查看动作卡；
- 调整顺序；
- 删除。

操作：

- 点击动作主体：打开 P02；
- 拖动排序，或使用“上移／下移”：改变练单保存的顺序；
- 点击删除：从该练单移除，不影响收藏和其他练单；
- 删除最后一个动作后保留空练单，用户可以继续添加或删除整份练单。

### 10.9 肌群概览

显示整份练单主要覆盖的身体部位和具体肌群，并区分主要肌群与辅助肌群。

操作：

- 点击某个练单动作：概览切换为该动作的主要和辅助肌群；
- 点击“查看全部覆盖”：恢复整份练单概览；
- 点击某个肌群的“添加相关动作”：进入 P04，并应用对应筛选。

如果前端暂时无法实现可点击人体 SVG，可以先用肌群名称列表和对应动作数量完成相同信息，不影响主流程。

### 10.10 练单助手

当练单中至少有一个动作时，展示“接下来可以考虑”，最多 3 个候选。

每个候选显示：

- 动作名称；
- 主要肌群；
- 来源视频；
- 一句推荐理由；
- “加入”；
- “不感兴趣”。

允许出现的推荐理由：

- “补充当前还没有覆盖的肩后束”；
- “你之前练这个动作时，目标部位感觉不错”；
- “这是你收藏但还没有练过的动作”；
- “同样练肩，但主要肌群与当前动作不同”。

禁止使用“最适合你”“最佳动作”“已经为你生成科学计划”等表达。

操作：

- 点击“加入”：加入当前练单末尾并更新肌群概览；
- 点击候选主体：打开 P02，返回后仍停留在当前练单；
- 点击“不感兴趣”：隐藏该候选并读取下一候选；
- 没有合适候选时显示“暂时没有更合适的候选，你可以从动作库继续添加”。

### 10.11 保存与再次使用

- 练单至少加入一个动作后才可以开始训练；
- 点击“开始训练”时，复制当前练单的动作和顺序，创建一次独立的本次训练记录；
- 本次训练的完成进度、跳过动作和体感只写入训练记录，不自动改动练单；
- 用户以后从 P03 再次点击“开始训练”，会创建一条新的训练记录；
- 编辑已保存练单只影响之后使用的版本，不影响过去的训练记录；
- “复制一份”会生成新的练单，名称默认为“原名称 副本”。

## 11. P04 动作选择页

### 11.1 页面目的

从具体的视频动作卡中选择一张，加入当前正在编辑的练单。

### 11.2 页面信息

从上到下展示：

1. 返回当前练单，并显示练单名称；
2. 搜索框；
3. 身体部位、肌群和器械筛选；
4. 最多 3 个练单助手候选；
5. 其他视频动作卡列表。

### 11.3 视频动作卡列表项

显示：

- 示范画面；
- 动作名称；
- 来源创作者；
- 主要肌群；
- 器械；
- 是否收藏、是否练过；
- “加入”。

同一个标准动作可以出现多张来自不同视频的视频动作卡，必须显示来源，不能只显示相同的动作名称。

### 11.4 操作

- 输入关键词：按动作名称、肌群、器械或视频标题筛选；
- 点击筛选项：更新结果；
- 点击卡片主体：打开 P02；
- 点击“加入”：加入当前练单并返回 P03A；
- 点击返回：不添加，回到 P03A；
- 已在练单中的卡片显示“已加入”，不能重复添加。

## 12. P05 动作库

### 12.1 页面目的

管理用户已经收藏、导入或练过的视频动作卡。

### 12.2 页面信息

1. 搜索；
2. “粘贴抖音链接”；
3. 身体部位和器械筛选；
4. 已收藏；
5. 最近练过；
6. 目标部位感觉不错；
7. 全部视频动作卡。

P0 列表的主体是视频动作卡，不是标准动作百科。

### 12.3 操作

- 点击“粘贴抖音链接”：输入链接后进入 P01；
- 点击视频动作卡：进入 P02；
- 点击“加入练单”：打开“选择练单”面板，选择已有练单或新建练单；
- 加入后提供“查看这份练单”：进入 P03A；
- 搜索或筛选只影响当前列表。

### 12.4 空状态

如果没有任何视频动作卡，显示：

> 还没有动作卡。把一条健身教学视频交给练过，从第一张卡开始。

提供“粘贴抖音链接”。

## 13. P06 训练执行页

### 13.1 页面目的

让用户在器械旁快速确认动作并完成训练，不需要重新拖动原视频。

### 13.2 页面信息

从上到下展示：

1. 训练进度，例如“2／3”；
2. 当前动作名称；
3. 当前视频来源；
4. 视频动作卡的训练速记内容；
5. “查看完整步骤”；
6. “查看原片段”；
7. 上一个、练过、跳过／下一个；
8. 退出训练。

### 13.3 操作

- 点击“查看完整步骤”：打开当前卡的完整步骤，返回后训练进度不变；
- 点击“查看原片段”：从对应时间打开视频，关闭后回到当前训练；
- 点击“上一个”：回到上一动作；
- 点击“跳过”：标记为跳过并进入下一动作，跳过不算练过；
- 点击“练过”：打开 P07 练后体感面板；
- 点击退出：选择保存并退出或继续训练。

### 13.4 状态恢复

系统保存：

- 当前训练到第几个动作；
- 哪些动作已完成、跳过或未开始；
- 已经提交的体感；
- 当前打开的是速记还是完整步骤。

## 14. P07 练后体感面板

### 14.1 页面目的

用一次或两次点击记录真实体感，并决定是否需要练友经验帮助。

### 14.2 第一问

问题：

> 这次练下来感觉怎么样？

单选项：

1. 目标部位有感觉；
2. 其他部位更酸；
3. 没找到明显感觉；
4. 动作有点吃力；
5. 出现不适。

### 14.3 分支一：目标部位有感觉

点击后：

1. 保存该动作和“目标部位有感觉”；
2. 显示本次目标肌群已记录；
3. 短暂展示健身搭子反馈；
4. 自动进入下一动作；
5. 该记录以后可以成为推荐理由。

### 14.4 分支二：其他部位更酸

点击后进入第二问：

> 哪个部位感觉更明显？

展示与当前动作有关的常见部位，并提供“其他”。

选择后：

1. 保存目标肌群和实际体感部位；
2. 将反馈转成问题标签，例如“手臂代偿”；
3. 按“标准动作 + 问题标签”读取已经生成的练友经验；
4. 显示一张相关经验提示卡；
5. 用户可选择“查看练友经验”或“先继续训练”。

选择“查看练友经验”进入 P08；选择“先继续训练”则记录反馈并进入下一动作。

### 14.5 分支三：没找到明显感觉

点击后：

1. 保存“没找到明显感觉”；
2. 将反馈映射为“目标肌群无感”；
3. 显示当前动作暗号；
4. 显示与“无感”最相关的练友经验提示卡；
5. 用户可查看 P08 或继续训练。

不得提示“你的动作做错了”，因为系统没有进行摄像头判断。

### 14.6 分支四：动作有点吃力

点击后：

1. 保存“动作有点吃力”；
2. 下次主动推荐时降低该卡的优先级；
3. 如果有“重量选择”或“动作控制”相关经验，提供查看入口；
4. 用户也可以直接继续训练。

系统不能自动给出具体重量、组数或次数。

### 14.7 分支五：出现不适

点击后立即进入 P09：

- 不展示普通练友经验作为解决方案；
- 不继续推荐当前动作；
- 不判断疾病或受伤原因。

### 14.8 关闭规则

- 提交前关闭：不保存，回到当前训练动作；
- 提交后返回：反馈已保存，不重复询问；
- 用户可以在训练完成前修改已保存的非安全反馈；
- “出现不适”记录只能明确撤销，不能被普通反馈直接覆盖。

## 15. 健身搭子反馈

健身搭子是「练过」里的小人 IP。它既会在提交体感后给出短暂反馈，也会长期显示在“我的”页面中。

### 15.1 显示内容

- 本次动作名称；
- 记录到的目标肌群或实际体感部位；
- 一句完成反馈；
- “继续下一个动作”。

### 15.2 显示规则

- “目标部位有感觉”：显示目标肌群；
- “其他部位更酸”：显示实际选择的部位；
- “没找到明显感觉”：不显示虚假的肌群点亮，只显示“已记录”；
- “动作有点吃力”：只显示“已记录，下次推荐会参考”；
- “出现不适”：不显示庆祝反馈，直接进入安全提示。

健身搭子只庆祝用户完成和记录，不表达一次训练已经改变身体。

## 16. P08 练友经验页

### 16.1 页面目的

让用户看到：同一个动作的问题并不只存在于当前视频，AI 已经把多个相关视频评论区的真实经验整理到一起。

### 16.2 进入方式

1. 从视频动作卡主动进入：默认显示该动作的热门问题；
2. 从“其他部位更酸”进入：直接打开与实际体感部位匹配的问题；
3. 从“没找到明显感觉”进入：直接打开“目标肌群无感”；
4. 从“动作有点吃力”进入：直接打开“重量或动作控制”；
5. 从训练中进入时，页面必须保留“返回训练”。

### 16.3 页面顶部

显示：

- 标准动作名称；
- 当前问题；
- 来源说明；
- 最后整理时间；
- 返回动作卡或返回训练。

来源说明必须具体，例如：

> AI 整理自 4 条哑铃侧平举视频下的 68 条公开评论

如果只使用了当前一条视频的评论，不能宣传为跨视频经验。

### 16.4 第一层：AI 整理结果

按“解决方法”显示多个经验组，例如：

- 降低重量；
- 由手肘带动；
- 不要为了抬高而耸肩；
- 控制下放速度。

每个经验组显示：

1. 一句容易理解的总结；
2. 有多少条公开评论提到；
3. 来自多少条不同视频；
4. 是否存在不同意见；
5. “查看依据”。

样本较少时只写“有 3 条评论提到”，不使用“多数人”“80% 有效”等确定说法。

### 16.5 第二层：查看依据

点击某个经验组的“查看依据”后，展开或进入原评论列表。

每条依据显示：

- 原评论内容；
- 来源视频标题；
- 创作者；
- 查看原视频或原评论；
- “对我有用”；
- 举报。

如果评论回复中包含具体方法，可以与原问题一起展示，但必须保留上下文。

### 16.6 第三层：当前视频是否提到

如果当前视频提到了这个问题，显示：

> 当前视频在 00:24 提到：不要为了抬高而耸肩。

并提供“查看原片段”。

如果当前视频没有提到，显示：

> 当前视频没有讨论这个问题，以上内容来自其他同动作视频下的公开评论。

这部分用于防止用户把练友经验误认为当前创作者观点。

### 16.7 页面操作

- 切换热门问题：更新 AI 整理结果；
- 点击经验组：查看依据；
- 点击“对我有用”：记录帮助度，不自动认定方法正确；
- 点击来源视频：打开对应视频或视频动作卡；
- 点击“返回训练”：回到 P06 当前动作；
- 点击“我也遇到了”：记录问题频次，但默认不公开个人训练记录。

### 16.8 空状态

没有匹配经验时显示：

> 暂时没有足够的同动作公开评论可以整理。

仍可以：

- 查看当前视频原片段；
- 返回训练；
- 提交一个问题，但默认作为个人草稿，用户明确发布后才公开。

### 16.9 安全规则

如果问题或评论涉及疼痛、麻木、眩晕、受伤或其他风险：

- 不把普通经验放在最前面；
- 显示停止动作和寻求专业帮助的提示；
- 所有社区内容标记“个人经验，不是诊断”；
- 隐藏明显危险建议并提供举报；
- 不承诺某个调整可以消除疼痛。

## 17. P09 不适安全提示页

### 17.1 页面信息

1. 标题“先停止当前动作”；
2. 说明系统不能判断不适原因；
3. 提醒持续、明显或突然的不适应咨询教练、康复师或医疗专业人员；
4. 当前动作名称；
5. “结束这个动作”；
6. “退出本次训练”；
7. “查看原视频的一般动作提示”；
8. “举报危险内容”。

### 17.2 操作

- 点击“结束这个动作”：标记该动作因不适停止，并进入下一动作；
- 点击“退出本次训练”：保存进度后进入 P10，标明未完成；
- 点击“查看原视频的一般动作提示”：只展示来源视频内容，不展示诊断；
- 当前动作从之后的主动推荐中排除，除非用户在“我的”中明确恢复。

## 18. P10 训练完成页

### 18.1 页面目的

让用户清楚看到哪些视频内容今天真的被用过，以及系统记录了什么。

### 18.2 页面信息

1. “本次训练完成”或“本次训练已结束”；
2. 完成、跳过和因不适停止的动作数量；
3. 每个视频动作卡的名称和来源；
4. 每个动作的体感摘要；
5. 本次涉及的目标肌群和实际体感部位；
6. 哪些记录会影响下次推荐；
7. 本次使用的来源练单；
8. “返回练单”；
9. “查看最近练过”。

示例：

```text
今天练过 2 个动作

哑铃侧平举｜肩中束有感觉
哑铃前平举｜手臂感觉更明显，已查看练友经验

下次选择动作时，会参考这两条体感记录。
```

### 18.3 操作

- 点击某个动作：打开对应 P02；
- 点击体感摘要：查看或修改本次非安全反馈；
- 点击来源练单：回到 P03A，查看保存的练单内容；
- 点击“返回练单”：进入 P03，原练单仍保留并可以再次使用；
- 点击“再次使用这份练单”：直接基于原练单创建新训练记录；如果本次训练不是来自已保存练单，则先询问是否保存为新练单。

## 19. P11 我的

“我的”既展示个人训练记录，也展示健身搭子小人 IP。健身搭子应出现在页面前部，而不是藏在设置中。

### 19.1 页面信息

- 头像和昵称；
- 我的健身搭子；
- 累计练过动作数；
- 最近练过；
- 最近训练到的身体部位；
- 目标部位感觉不错的动作；
- 曾经反馈不适的动作；
- 我的公开问题和经验；
- 隐私与数据设置。

### 19.2 健身搭子模块

模块显示：

- 完整的健身搭子小人；
- 用户为搭子设置的昵称，未设置时显示“我的健身搭子”；
- 最近一次训练后记录到的身体部位；
- 累计陪用户完成的训练次数；
- 一句与最近记录有关的反馈；
- “查看我的训练记录”。

规则：

- P0 使用团队准备好的固定小人 IP，不需要用户上传真人照片；
- 最近练过的部位可以在小人身上对应显示，同时必须配有部位文字；
- 没有训练记录时显示初始状态，并提示“完成第一次训练后，搭子会记住你练过的部位”；
- “没找到感觉”不能被显示成已经练到目标肌群；
- “出现不适”不使用庆祝内容，只显示安全记录入口；
- 健身搭子反映的是训练和记录，不代表身体已经发生外形变化。

### 19.3 操作

- 点击健身搭子：展开最近训练部位和对应动作记录；
- 点击“查看我的训练记录”：打开最近练过列表；
- 点击最近练过：打开训练记录；
- 点击具体动作：打开对应视频动作卡；
- 点击不适动作：可查看记录并决定是否恢复主动推荐；
- 点击公开内容：查看、编辑或删除自己主动发布的内容；
- 训练反馈默认私密，只有用户明确发布后才进入公共练友经验。

## 20. K01 P1 动作知识页

该页面写进产品规划，但不进入 P0 开发和主 Demo。

### 20.1 页面目的

围绕一个标准动作，查看多个视频本身的教学内容、练友经验和足量反馈形成的完整知识。

### 20.2 进入方式

- P1 动作库增加“查看动作知识”；
- 视频动作卡增加“查看这个动作的完整知识”；
- 练友经验页增加“查看动作知识”。

它不是新的底部一级入口。

### 20.3 页面内容

1. 标准动作名称、别名、主要肌群和器械；
2. **多个视频共同强调**：反复出现的教学要点；
3. **不同视频有不同说法**：列出观点、适用条件和来源；
4. **相关视频动作卡**：每张卡保留创作者和原视频；
5. **练友经验**：直接使用 P0 已形成的经验聚类；
6. **真实训练反馈**：只有达到样本门槛并去掉个人身份后才显示；
7. **我的记录**：只对当前用户展示；
8. 更新时间和知识版本。

### 20.4 操作

- 点击共识或不同观点：查看支持它的来源视频和时间位置；
- 点击相关视频：进入对应 P02；
- 点击练友问题：进入 P08；
- 点击“加入练单”：必须先选择一张具体视频动作卡，再选择已有练单或新建练单；不能把抽象知识页直接加入练单；
- 用户反馈只能用于改善聚合结果，不能修改原视频卡片。

## 21. 前端需要统一保存的页面状态

### 21.1 视频动作卡状态

- 是否生成完成；
- 是否收藏；
- 已经加入了哪些练单；
- 默认打开完整步骤还是训练速记；
- 是否有可靠示范片段；
- 是否有关联练友经验。

### 21.2 保存的练单状态

每份练单至少保存：

- 练单 ID；
- 练单名称；
- 视频动作卡 ID 和顺序；
- 创建时间和最后修改时间；
- 最近使用时间；
- 已使用次数；
- 草稿或已保存状态。

删除练单不能连带删除视频动作卡和过去的训练记录。

### 21.3 本次训练状态

- 进行中；
- 已完成；
- 已中途结束。

本次训练还要保存来源练单 ID、开始时复制的动作与顺序，以及每个动作的未开始、已完成、已跳过或因不适停止状态。

### 21.4 体感值

前后端统一使用以下五种值，界面显示中文：

| 保存值 | 界面文字 |
| --- | --- |
| `TARGET_FELT` | 目标部位有感觉 |
| `OTHER_FELT` | 其他部位更酸 |
| `NO_FEELING` | 没找到明显感觉 |
| `TOO_HARD` | 动作有点吃力 |
| `DISCOMFORT` | 出现不适 |

`OTHER_FELT` 还必须保存用户选择的实际体感部位。

### 21.5 练友经验查询条件

前端请求练友经验时至少传入：

- 标准动作 ID；
- 问题标签；
- 当前来源视频 ID；
- 是否从训练中进入。

后端返回：

- 当前问题；
- 评论总数；
- 来源视频数量；
- 经验组；
- 每组提及数量和不同意见；
- 原评论和来源视频入口；
- 是否触发安全提示。

### 21.6 健身搭子状态

至少保存：

- 搭子昵称；
- 累计陪伴完成的训练次数；
- 最近一次训练时间；
- 最近记录到的目标部位或实际体感部位；
- 最近一次是否包含不适记录；
- 用于“我的”页面展示的最近动作摘要。

## 22. 页面之间的数据变化

| 用户操作 | 立即发生的数据变化 | 页面结果 |
| --- | --- | --- |
| 导入视频 | 创建或查询公共视频卡 | 进入 P01 |
| 动作卡生成完成 | 保存视频卡并关联标准动作 | 可进入 P02 |
| 收藏动作卡 | 当前用户与卡片建立收藏关系 | P02、P05 同步显示已收藏 |
| 新建练单 | 创建空练单草稿 | 进入 P03A |
| 加入练单 | 卡片 ID 加到用户选择的练单末尾 | P02、P03A、P04、P05 同步更新 |
| 调整顺序 | 更新保存练单中的顺序 | P03A 立即更新并显示已保存 |
| 开始训练 | 复制当前练单内容并创建独立训练记录 | 进入 P06，原练单保留 |
| 点击练过 | 打开体感选择，不立即完成动作 | 进入 P07 |
| 提交普通体感 | 保存动作完成和体感 | 进入下一动作或 P08 |
| 提交不适 | 保存安全记录并停止当前动作 | 进入 P09 |
| 标记经验有用 | 保存当前用户对经验的帮助度 | P08 显示已标记 |
| 完成最后一个动作 | 完成本次训练记录 | 进入 P10 |
| 再次使用练单 | 从同一练单创建新的训练记录 | 进入新的 P06 |

## 23. Demo 必须准备的数据

### 23.1 视频与动作卡

至少准备：

- 哑铃侧平举主视频及其真实生成动作卡；
- 2—4 条同为哑铃侧平举的预置来源视频；
- 哑铃前平举、反向飞鸟、坐姿推肩等候选视频动作卡；
- 每张卡的来源、步骤、动作暗号、主要肌群、辅助肌群和示范片段。

### 23.2 练友经验

主问题：

> 做哑铃侧平举时，为什么手臂比肩部更有感觉？

至少准备三个经验组：

1. 降低重量；
2. 由手肘带动；
3. 不要为了抬高而耸肩。

每个经验组至少准备：

- 摘要；
- 提及条数；
- 来源视频数量；
- 2—3 条可展开的原评论；
- 一条不同意见或“暂无明显分歧”；
- 原视频入口。

### 23.3 历史体感

至少准备：

- 一个“目标部位有感觉”的历史动作，用于推荐理由；
- 一个“没找到明显感觉”的历史动作，用于降低排序；
- 一个“不感兴趣”的动作；
- 一个“出现不适”的动作，用于排除主动推荐。

### 23.4 已保存练单与健身搭子

至少准备两份已保存练单：

- “今天练肩”：包含哑铃侧平举、哑铃前平举，可在主 Demo 中新建并保存；
- “上次练背”：包含 2—3 张视频动作卡，用于证明旧练单能够再次使用。

健身搭子至少准备：

- 固定的小人 IP；
- 搭子昵称；
- 累计完成训练次数；
- 最近一次记录到的肩部训练；
- 无训练记录时的初始状态；
- 出现不适时不庆祝的状态。

## 24. P0 可点击原型必须走通的路径

### 24.1 视频变动作卡

```text
P00 模拟抖音
  → P01 视频接入与处理
  → P02 视频动作卡完整步骤
  → 切换训练速记
```

### 24.2 动作卡加入练单

```text
P02 加入练单
  → 选择“新建练单”
  → P03A 命名并编辑练单
  → P04 添加第二张卡
  → P03A 调整顺序并自动保存
```

### 24.3 正常完成

```text
P03A 开始训练
  → P06 训练执行
  → P07 选择目标部位有感觉
  → 健身搭子反馈
  → 下一动作
```

### 24.4 问题反馈与练友经验

```text
P06 点击练过
  → P07 选择其他部位更酸
  → 选择手臂
  → P08 查看跨视频练友经验
  → 展开原评论
  → 标记对我有用
  → 返回 P06
```

### 24.5 结束训练

```text
完成最后一个动作
  → P10 训练完成页
  → 返回练单或查看动作卡
```

### 24.6 保存后再次使用

```text
P03 练单首页
  → 打开以前保存的练单
  → P03A 查看练单内容
  → 开始训练
  → 创建新的本次训练记录
```

### 24.7 安全分支

```text
P07 选择出现不适
  → P09 停止动作提示
  → 结束当前动作或退出训练
```

## 25. 必须覆盖的空状态和异常状态

设计和前端至少准备以下状态：

1. 视频动作卡已存在；
2. 视频动作卡生成中；
3. 视频解析失败；
4. 无法确认标准动作；
5. 动作库为空；
6. 没有任何已保存练单；
7. 新建练单中还没有动作；
8. 练单只有一个动作但可以开始；
9. 已经有一份未完成训练，又准备开始另一份练单；
10. 没有合适的推荐候选；
11. 练友经验样本不足；
12. 没有与当前体感匹配的经验；
13. 训练中短暂断网并恢复；
14. 用户中途退出后继续训练；
15. 用户反馈出现不适；
16. 来源视频或原评论暂时无法打开。

每个异常状态都要告诉用户发生了什么，以及下一步可以做什么，不能只显示“出错了”。

## 27. 最终验收标准

所有组员看完原型后，应能回答以下问题：

1. 用户从哪里得到视频？
2. 一条视频怎样变成一张视频动作卡？
3. 视频动作卡和标准动作有什么区别？
4. 用户实际加入练单的是哪一个？
5. AI 在哪里帮助用户，哪里不能替用户做决定？
6. 用户训练后怎样提交体感？
7. 什么反馈会触发练友经验？
8. 练友经验为什么是跨视频的？
9. 练友经验如何保留原评论和原视频来源？
10. P0 动作关联层和 P1 动作知识库有什么区别？
11. 用户出现不适时系统怎样处理？
12. 新建的练单怎样保存并在以后再次使用？
13. 开始训练后为什么不会改乱原来的练单？
14. “我的”页面怎样展示健身搭子及其训练记录？
15. 用户返回或刷新页面后，练单和训练进度是否保留？

可点击 Demo 还必须满足：

- 从模拟抖音进入到完成一次训练，可在 2—3 分钟内走完；
- 用户不填写 AI 表单也能直接添加动作并开始训练；
- 推荐动作不会自动加入练单；
- 用户可以新建、命名和保存练单，并从练单首页再次使用；
- 训练速记、练过按钮和体感反馈都能在主流程中真实点击；
- “其他部位更酸”或“没找到感觉”能打开对应的跨视频练友经验；
- 用户能够从 AI 摘要继续查看原评论和来源视频；
- 单视频动作卡始终只包含本视频内容；
- “我的”页面能够看到健身搭子小人和最近训练记录；
- P1 动作知识库不会被误认为 P0 必须完成的页面。
